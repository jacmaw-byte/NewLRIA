# LRIA

This is a 2D, procedurally generated game I'm working on. It currently has some resemblance of a UI system, an infinite procedural 2d world and player collisions and movement. 
It uses the Light Weight Java Game Library to render to the screen and the Java OpenGl Maths Library for linear algebra.

Many things are a work in progress most notably the UI.

IDK how to run it. Just run in in intellij idea and it should work. I haven't tested it on windows, only on linux so it will probably need some tweaks to run.
